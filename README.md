# yt-dlp 视频下载工具

基于 C++、Qt 开发的图形化视频下载工具，使用 yt-dlp 下载视频，并通过 FFmpeg 处理音视频。

## 功能

- 输入视频 URL
- 查看可用视频格式
- 下载视频或音频
- 实时显示下载日志
- 自定义下载路径

## 运行环境

- Windows 10 / 11
- Qt 6
- yt-dlp
- FFmpeg

## 使用方法

1. 从 GitHub Releases 下载程序压缩包。
2. 解压到任意目录。
3. 双击 `ytdownload.exe` 启动程序。
4. 输入视频 URL，选择格式和保存路径。
5. 开始下载。

无需手动配置系统环境变量。
